# Yapay Zekâ Rehberi - Proje Ödevi

## Projenin Amacı
Bu web sitesi, BPR201 İnternet Tabanlı Programlama dersi kapsamında yapay zekâ alanındaki en popüler beş uygulamayı (ChatGPT, Midjourney, DeepL, ElevenLabs, GitHub Copilot) tanıtmak ve ziyaretçilerin içerikleri başlıklarına göre arayabilmesini sağlamak amacıyla geliştirilmiştir.

## Kullanılan Teknolojiler
* HTML5
* CSS3
* JavaScript (DOM Manipulation)

## Çalıştırma Adımları
1. Projeyi bilgisayarınıza indirin veya Codespaces üzerinde açın.
2. `index.html` dosyasını herhangi bir web tarayıcısında (Chrome, Edge vb.) açarak siteyi görüntüleyin.
